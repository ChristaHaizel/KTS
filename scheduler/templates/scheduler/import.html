How it works
  • All or nothing. Every row is checked before anything is written. One bad row rejects the whole file, and you get every problem listed at once rather than one per attempt.
  • Re-uploading is safe. Rows are matched on the identifier they already carry, so a corrected file updates the existing records instead of creating duplicates.
  • References must exist. A course naming an unknown lecturer, or a student naming an unknown group, is reported as an error rather than quietly creating one - which is what stops a typo splitting a cohort in two.
  • Logins are separate. Importing people does not create accounts. Use the Create account buttons on the Lecturers and Students pages, so passwords appear in your browser and nowhere else.
