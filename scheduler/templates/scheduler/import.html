How it works
  • The file has to be the right kind. That is decided by the header row, so a Rooms file uploaded into Lecturers is refused and tells you where it belongs. That is the only thing checked before loading.
  • Everything loadable is loaded. A few unusable rows do not stop the rest; they are listed afterwards. A row is only skipped when the record cannot exist without what is missing - a lecturer with no email, a room with no capacity.
  • Missing references are created. A student naming a group that does not exist yet, or a course naming a new lecturer, creates it. The count is reported so nothing appears unannounced.
  • Re-uploading is safe. Rows are matched on the identifier they already carry, so a corrected file updates the existing records instead of creating duplicates.
  • Logins are separate. Importing people does not create accounts. Use the Create account buttons on the Lecturers and Students pages, so passwords appear in your browser and nowhere else.
